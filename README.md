# Lord Nine Tools

This is a Next.js companion app for an MMORPG, generated by Firebase Studio.

## Features

- **Character Stats Tracker**: Track your character's stats and equipped gear, with AI-powered suggestions for optimization.
- **Quest Management**: Keep track of your active quests and their objectives.
- **Item Database**: Search and browse a comprehensive database of in-game items, with an AI assistant to help you find what you need.
- **Skill Tree Planner**: Plan your character's skill builds for different classes.

## Getting Started

To get started, run the development server:

```bash
npm run dev
```

Then, open [http://localhost:9002](http://localhost:9002) with your browser to see the result.
